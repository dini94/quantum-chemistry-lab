Electronic properties

Conceptual-DFT descriptors

HOMO/LUMO-derived values are Koopmans-style estimates, not substitutes for ΔSCF ionization energies/electron affinities.

Thermodynamics

Thermochemical values depend on a frequency calculation, temperature, pressure, solvent/model chemistry and standard-state corrections.

Structural parameters

Bond connectivity is estimated from covalent radii; verify unusual bonds, coordination complexes, and transition-metal structures.

Orbital / ESP cube viewer

Upload a cube file to render a 3D isosurface.

For orbital cubes, both positive and negative phases are displayed in contrasting colors. ESP cubes need a matching electron-density surface to produce a molecular ESP map; a single ESP cube alone is not a complete mapped surface.

Multiwfn workflow assistant

Multiwfn is an external scientific executable and cannot run inside static GitHub Pages. This panel prepares a workflow for local/HPC use and can display a text report generated by Multiwfn; it does not pretend to run Multiwfn in the browser.
