What this browser builder can do

• Parse and validate SMILES, show 2D structure and descriptors.
• Start from molecular fragments or replace a scaffold attachment point.
• Generate a 3D conformer, MMFF94-clean it, and export XYZ/SDF.
• Generate a small substituent series and download CSV.

It does not run Gaussian/ORCA/DFT in the browser. For atom-by-atom freehand drawing, use a dedicated molecular sketcher and import its SMILES here.
RDKit.js · OpenChemLib · 3Dmol.js · Static GitHub Pages; no API calls are used for molecular calculations.
