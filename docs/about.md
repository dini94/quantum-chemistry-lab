# About this project

Quantum Chemistry Lab is a modular learning resource for computational chemistry. It helps learners understand the reasoning behind calculations and the steps needed to make results reproducible.

## Scope

The website provides educational material, input examples, workflow checklists, and a lightweight client-side demo. It is not affiliated with or endorsed by Gaussian, ORCA, or the software projects mentioned unless explicitly stated by those projects.

## Scientific responsibility

Templates must be adapted and validated for each system. Users are responsible for checking licenses, software manuals, convergence, and scientific interpretation before using results in research or publication.
