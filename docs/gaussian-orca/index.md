## Gaussian and ORCA are calculation engines

- **Gaussian:** proprietary quantum chemistry software. Use an installation covered by the applicable license.
- **ORCA:** available without charge for eligible academic/non-commercial uses under its license terms. Read the current license before institutional or public deployment.

This website does not bundle either program and does not execute calculations. The browser demo is illustrative only.

## Recommended workflow

1. Define the scientific question and property to calculate.
2. Choose the method and model chemistry with a defensible rationale.
3. Build and validate the molecular structure.
4. Prepare input files and run calculations in an authorized installation.
5. Check convergence, warnings, stationary-point type, and numerical consistency.
6. Analyze the output and create reproducible plots and tables.
