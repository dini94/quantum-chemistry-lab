## Important scope note

This site is a learning resource, not a public quantum-chemistry compute server. Its interactive demo uses illustrative examples and does **not** execute Gaussian or ORCA. Run real calculations with an authorized local or institutional installation, then validate the output.

## Suggested route

1. Start with the [learning paths](learning-paths.md).
2. Review [theory and method selection](gaussian-orca/theory.md).
3. Build and validate a molecular structure and prepare an [input file](gaussian-orca/input-builder.md).
4. Run the calculation in Gaussian or ORCA and inspect [the output](gaussian-orca/results-analysis.md).
5. Follow the [publication workflow](gaussian-orca/publication.md).
