## Interactive learning

Use the interactive demo to explore the stages of a computational chemistry workflow.

**Important:** The initial simulator demonstrates the workflow and interface only. It does not execute real quantum chemistry calculations.

[Open the interactive demo](simulator/)

## Learning approach

1. **Understand** the physical and chemical concepts.
2. **Prepare** molecular structures and input files.
3. **Calculate** using the appropriate computational software.
4. **Analyze** energies, structures, orbitals, and spectra.
5. **Validate** the results and document the workflow.
