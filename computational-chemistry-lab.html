1 · Computational chemistry: why it matters

Simulation complements experiment by testing mechanisms, resolving atom-level contributions, screening candidates, and prioritizing experiments. Predictions depend on the model, approximations, sampling, and validation.

Model → Solve → Validate

Structure and conditions → theory and algorithms → observables → comparison with experiment.

Applications

  • Drug discovery: virtual screening across large chemical spaces.
  • Catalysis/materials: energetics, mechanisms, active sites.
  • Photochemistry: excited states and spectra.

2 · Schrödinger equation and many-electron scaling

Ĥ Ψ(r₁,…,rₙ) = E Ψ(r₁,…,rₙ)

For N electrons, Ψ depends on 3N spatial coordinates (plus spin). Electron correlation couples coordinates; accurate wavefunction representations become rapidly expensive.

Why direct solution is difficult

  • High-dimensional many-electron wavefunction.
  • Electron–electron interaction couples variables.
  • Exact methods scale steeply with system size.
  • Approximations require validation.

3 · Density Functional Theory

DFT uses electron density ρ(r) as the central variable. Kohn–Sham orbitals reproduce that density; exchange-correlation effects are represented by an approximate functional.

E[ρ] = Ts[ρ] + Eext[ρ] + J[ρ] + Exc[ρ]

Functional families

LDA · GGA (PBE) · meta-GGA (SCAN) · hybrid (B3LYP/PBE0) · range-separated (ωB97X)

Method choice depends on target property. Check basis, dispersion, solvent, spin, grids, and convergence.

4 · SCF: self-consistent field loop

Guess density → build effective Hamiltonian → solve orbitals → new density → mixing → convergence test.

Ready

Run to see energy converge.

ρₖ → F[ρₖ] → {φᵢ, εᵢ} → ρₖ₊₁
Educational curve, not a molecular calculation.

5 · Reproducibility workflow

  1. Define charge, multiplicity, conformers, environment and boundary conditions.
  2. Choose method, basis/pseudopotential, dispersion, solvent, grids and k-points.
  3. Converge SCF, geometry, cutoff, basis, supercell and sampling.
  4. Validate relevant observables against experiment or benchmarks; report uncertainty.

ORCA Docker / container workflow

Containerization improves reproducibility; Docker is not a separate quantum method. Use only an authorized ORCA image/license.

docker run --rm -it \
  -v "$PWD:/work" -w /work \
  <authorized-orca-image> \
  orca molecule.inp > molecule.out
  • Pin image tag/digest and record ORCA version.
  • Mount writable working directory.
  • Align CPU/memory limits with PAL and maxcore.
  • Preserve input, output, restart files, and environment metadata.
  • Never commit license credentials to a public repository.

Image name and license arrangement depend on your institution's deployment.
